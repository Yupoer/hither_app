Hither 5 大入口畫面重構設計稿與規格標註

包含各畫面之真實高解析截圖、UI 元件與 ICON 相對尺寸/比例、幾何邊距、排版字體、色彩 Token 與 React Native 落地樣式代碼。

Screen 1 登入 (Sign In)
■分段標籤：寬度 190px 居中膠囊。
■社群按鈕：直徑 64px 圓形，間距 32px。
■圖標比例：剛好佔外框 1/2 直徑 (32px)。
■忘記密碼：密碼輸入框右下方配置。
■同意條款：登入頁完全不展示。
Screen 2 註冊 (Sign Up)
■極簡表單：信箱、密碼、確認密碼。
■無暱稱欄位：徹底刪除暱稱輸入。
■無快速連結/社群：徹底清空下方按鈕。
■密碼校驗：確認密碼右側綠勾。
■同意條款：專屬在此頁展示法定文字。
Screen 3 忘記密碼 (Forgot Password)
■左上角按鈕：簡約膠囊「返回」。
■純淨流程：說明文字 + 信箱輸入。
■主按鈕：全寬發送重設連結（無外發光）。
■底部：無多餘重複返回鍵。
Screen 4 主畫面 (Home: 創建/加入)
■雙大按鈕：正方形 (1:1 比例)。
■外框顏色：兩者外框色彩完全一致。
■創建圖標換新：專屬群組圖標，純白。
■文字水平齊平：鎖定 56px 等高圖標插槽。
■查看隊伍：高 50px 膠囊，下移 36px。
■刪除按鈕：已徹底移除。
Screen 5 我的隊伍 (My Teams)
■隊伍代碼字體：與「代碼」字體完全一致。
■代碼字級：14.5px 粗體無襯線字體。
■全域背景一致：相同顆粒流光底色。
■群組頭像：48×48px 圓角方框大頭貼。

相對位置與 8pt 幾何間隙規範

佈局關係 間隙數值 設計用意與對齊規則
社群按鈕彼此距離 gap: 32px 放大 2 倍間隙，讓 64px 圓形在畫面中自然舒展。
主畫面按鈕水平基準 差值 0px 兩方圖標均封裝於 56px 插槽，下方文字 Baseline 100% 齊平。
查看隊伍按鈕下移 margin-top: 36px 精準向下平移約半個按鈕高度，拉開操作層級呼吸感。
忘記密碼位置 top: 4px / bot: 14px 密碼輸入框右下方，符合手指直覺操作慣性。
欄位與標籤間隙 gap: 6px 標籤緊貼對應輸入框，欄位間隙固定為 14px。
