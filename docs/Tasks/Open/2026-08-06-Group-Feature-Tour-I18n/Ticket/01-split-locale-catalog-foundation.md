# 01 — 建立分語言文字目錄

**What to build:** 在不改變目前使用者畫面文字的前提下，建立每種語言一個完整檔案的文字目錄與單一翻譯入口，讓後續功能可以分批遷移且保持 App 可執行。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] 繁體中文與英文各自具有獨立、完整的語言檔。
- [x] 現有翻譯呼叫介面與參數代換行為保持相容。
- [x] 切換語言會更新已掛載畫面，不需重新啟動 App。
- [x] 自動測試驗證兩種語言的文字鍵完全一致。
- [x] 現有 Jest、型別檢查與 lint 保持通過。
