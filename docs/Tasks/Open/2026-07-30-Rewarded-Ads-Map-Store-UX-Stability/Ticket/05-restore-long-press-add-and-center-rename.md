# 05 — 修復長按新增並加入中央改名視窗

**What to build:** 讓使用者長按地圖後保留原本底部新增彈窗，點擊其中的名稱才開啟中央改名視窗；正式新增成功後，集合點同時穩定出現在卡片與地圖，鏡頭顯示自己和集合點，失敗時則保留草稿供重試。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 長按地圖會建立暫存位置、顯示旗幟，並開啟原本的底部新增地點彈窗。
- [ ] 長按後可先將鏡頭拉近所選位置，但尚未正式新增前不建立集合點卡片。
- [ ] 點擊底部彈窗中的地點名稱時，才在畫面中央開啟獨立輸入視窗；原本底部彈窗不被替換。
- [ ] 中央視窗提供清楚的「確定」與「取消」，鍵盤出現時輸入欄與兩個操作仍可見。
- [ ] 「確定」只在非空白名稱通過既有規則後更新待新增草稿並關閉中央視窗，不會直接新增集合點。
- [ ] 「取消」關閉中央視窗並保留開啟前的草稿名稱、位置與旗幟。
- [ ] 正式新增仍由底部彈窗原本的新增按鈕觸發，且重複點擊不會建立重複集合點。
- [ ] 領隊新增成功後，已保存集合點出現在新的集合點卡片與地圖旗幟，重新整理後仍存在。
- [ ] 新增成功後才清除暫存狀態，鏡頭調整至自己與新集合點均可見。
- [ ] 新增失敗時保留草稿名稱、位置、旗幟與底部彈窗，顯示錯誤並允許直接重試。
- [ ] 非領隊確認新增時維持送出持久化領隊請求，不直接寫入集合點；請求成功與失敗均有正確回饋。
- [ ] 自動化測試覆蓋確定、取消、空白名稱、新增成功／失敗、領隊／非領隊及成功後鏡頭。
- [ ] iOS MapKit 與 Android Google Maps 的可用環境完成互動檢查；缺少裝置證據時不得宣稱平台行為已通過。
