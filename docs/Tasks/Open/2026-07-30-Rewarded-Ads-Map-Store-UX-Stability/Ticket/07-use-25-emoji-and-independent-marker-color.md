# 07 — 改為 25 個 Emoji 並支援獨立旗幟顏色

**What to build:** 讓集合點管理者從固定 25 個 Emoji 與既有旗幟色盤分別選擇，在同一視窗預覽組合，按確定後一次儲存並同步到集合點列與地圖旗幟。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Emoji 清單固定為現有內建清單移除 `🧭` 後的 25 個選項。
- [ ] 選擇器不再顯示自訂 Emoji 輸入、說明或驗證錯誤入口。
- [ ] Emoji 網格左右容器留白相等，項目間距一致，窄螢幕與動態字級下不貼齊單側邊界。
- [ ] 每個 Emoji 儲存格使用一致的主題色框線；框線不再以各旗幟背景色區分。
- [ ] Emoji 與旗幟背景色是兩個獨立可選草稿，任一 Emoji 都可搭配既有色盤中的任一允許顏色。
- [ ] 視窗在確認前顯示目前草稿的 Emoji／背景色組合預覽。
- [ ] 按「取消」後，集合點列、地圖旗幟與持久化資料均維持開啟前的 Emoji／背景色。
- [ ] 按「確定」後，沿用既有集合點更新契約一次提交 Emoji 與背景色，不新增 schema、API 或第三方套件。
- [ ] 儲存成功後，集合點列與地圖旗幟立即呈現同一組合，重新整理與重新開啟後仍一致。
- [ ] 儲存失敗時保留選擇視窗與兩個草稿值、回復持久化畫面狀態、顯示可重試錯誤，不只寫入日誌。
- [ ] 既有或同步進來的非清單 Emoji 仍使用安全顯示 fallback，不讓資料讀取造成畫面崩潰；介面不提供建立新自訂值。
- [ ] 測試覆蓋固定數量、無自訂入口、獨立組合、確定、取消、失敗重試及重新讀取後地圖同步。
