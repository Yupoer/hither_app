# 06 — 讓調整順序整條可點擊並同步鉛筆動畫

**What to build:** 讓集合點管理者點擊「調整順序」整條區域的任何位置都能得到一致的震動與鉛筆動畫，並在動畫完成後進入既有排序模式，不必精準點擊小按鈕。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 「調整順序」整條可視區域是單一可點擊目標，文字、空白處與鉛筆區域都觸發相同行為。
- [ ] 不存在內外兩個競爭的 press handler，單次點擊只觸發一次震動、一次動畫與一次排序動作。
- [ ] 觸發後立即提供震動與鉛筆動畫回饋，既有排序業務動作在動畫完成邊界執行。
- [ ] 鉛筆在靜止、按下與動畫狀態都使用既有主題色，不回退成次要灰色。
- [ ] 動畫期間重複點擊不會疊加開啟多個排序介面或造成狀態錯亂。
- [ ] 整條操作具有正確的按鈕語意、可理解標籤、焦點與鍵盤／讀屏觸發能力。
- [ ] Reduced Motion 開啟時仍提供狀態回饋並完成排序動作，不依賴完整動畫才能操作。
- [ ] 測試從整條區域不同位置觸發，斷言只開啟一次既有排序模式，不鎖定動畫內部實作。
