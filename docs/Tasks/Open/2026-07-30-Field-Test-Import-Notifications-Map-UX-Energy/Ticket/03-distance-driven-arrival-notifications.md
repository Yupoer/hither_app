# 03 — 完成距離驅動的抵達通知

**What to build:** 成員自己的定位符合所設定的抵達距離與精度規則後，第一次成功保存抵達狀態時，成員本機收到一次確認，隊長收到一次成員抵達通知；重複定位與傳輸重播不會重複通知。

**Blocked by:** 02 — 統一本機、Realtime 與遠端通知政策.

**Status:** ready-for-agent

- [ ] 自動抵達沿用使用者設定的 arrival radius 與既有 accuracy-aware 狀態機，不使用固定 30 m 規則覆蓋設定。
- [ ] 只有自己的定位樣本能觸發自己的自動抵達；其他成員位置與隊長位置不會代替判定。
- [ ] 低精度或漂移樣本依既有連續 fix 規則處理，不會因單一不可信樣本誤判。
- [ ] 第一次成功保存 `(destination, user)` 抵達後，成員本機得到一次確認，該 group 的有效隊長得到一次成員抵達通知。
- [ ] 相同 destination 的重複 fix、App 重開、outbox 重試、Realtime 重播及 APNs／FCM 重送不會再次產生抵達通知。
- [ ] 不同 destination 的第一次抵達仍能各自通知。
- [ ] 手動抵達與自動抵達的通知來源可辨識，但都遵守同一去重與 recipient policy。
- [ ] 測試涵蓋距離邊界、定位精度、連續 fix、重複保存、不同集合點、solo／小隊與隊長收件人。
