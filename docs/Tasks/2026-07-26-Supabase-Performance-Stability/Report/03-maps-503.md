# Ticket 03 — Maps 503 classification

## Edge Function error matrix

| Condition | HTTP | `error` body |
|-----------|------|--------------|
| Missing auth token / invalid user | 401 | `unauthorized` |
| Invalid JSON / request | 400 | `invalid_input` |
| `consume_google_maps_quota` RPC error | 503 | `quota_rpc_failed` |
| Daily limit hit | 429 | `quota_exceeded` |
| Missing `SUPABASE_URL` or `GOOGLE_MAPS_SERVER_API_KEY` | 503 | `missing_config` |
| Google Places/Routes failure | 503 | `upstream_unavailable` |
| Client fetch failure | 0 | `network` (client-side only) |

## Client behavior

- In-flight dedupe + 45s success TTL retained
- Failure cooldown (no infinite retry):
  - quota_exceeded: 60s (**global** across all keys)
  - missing_config: 60s (**global**)
  - quota_rpc_failed: 30s (**global**)
  - unauthorized: 30s (per-key)
  - invalid_input: 15s (per-key)
  - upstream_unavailable: 8s (per-key only — other keys may still try)
  - network: 5s (per-key)
- Telemetry via `recordClassifiedError` with allow-listed `errorCode` (no dropped extra fields)
- Runtime Jest: in-flight share, TTL, same-key cooldown, global quota, different-key upstream
- `getDirections` still falls through to `null` → UI haversine / 估算 ETA
